# MacMinecraftTool

A Mac app that fixes a lot of the annoyances when playing Minecraft on a Mac. Open this app before starting Minecraft and quit it when you're done.

- **Control-click:** Keep left-clicking while holding Control. (By default Ctrl click = Right click on Mac)
- **Control-Q:** Drop a whole stack without client mods or quitting the game.
- **Function keys:** Use F1–F12 without holding Fn.
- **Shift-scroll:** Scroll normally while holding Shift. (By default holding shift switches scroll direction)
- **Pointer acceleration:** Turn it off for consistent mouse movement.
- **Quit reminder:** Get a notification when you've stopped playing reminding you to quit to restore default behavior

Control-click, Control-Q, and Shift-scroll require Accessibility permission in
System Settings → Privacy & Security → Accessibility.
